# Zapojení úlohy 2 (Analog I/O)

### Potenciometr (Analogový vstup):
- **Běžec (střední pin):** GP26 (fyzický pin 31, ADC0)
- **Krajní pin 1:** 3.3V (OUT) (fyzický pin 36)
- **Krajní pin 2:** GND (fyzický pin 38)

### Piezo bzučák (PWM výstup):
- **Pozitivní pin (+):** GP27 (fyzický pin 32, PWM výstup)
- **Negativní pin (-):** GND (fyzický pin 33 nebo jiný GND)
